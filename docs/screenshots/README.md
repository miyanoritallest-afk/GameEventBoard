# スクリーンショット / デモ動画 撮影ガイド

README に載せる画像・GIF の置き場と、**何を・どこで・どう撮るか**の手引き。
撮影は手動（画面収録 / GIF 録画ツール）で行い、ここにファイルを置くと README から参照される。

## 運用ルール
- **静止画**: PNG（`*.png`）。ページ全体または要点が分かる範囲。
- **動的な操作**: GIF（`*.gif`）。GitHub の README で `![](...)` により**自動再生**される。
  - 1本 10〜20 秒・要点に絞る（ファイルサイズ数 MB に収めるため）。ダラダラ長く撮らない。
  - 録画は等倍〜やや拡大で、カーソルの動きが分かるように。
- ファイル名は README の参照と一致させる（下表）。差し替え時は同名で上書き。

## デモに使うイベント
「**のり検証1**」（`/events/event-b3vrkk`）が**情報全部乗せ**（個人スコア計算あり・ロールスワップあり・チームスコア上限 30）で、5チーム・予選結果・決勝トーナメントまで揃っている。撮影はこのイベントで行うのがよい。

## 撮影後
1. 上記ファイル名で `docs/screenshots/` に置く。
2. README の該当プレースホルダ（`<!-- SCREENSHOT: ... -->` / `<!-- DEMO: ... -->`）を、対応する `![説明](docs/screenshots/xxx.png)` に置き換える。
3. GitHub 上で表示・再生を確認（GIF は自動再生、PNG は等倍表示）。
