# archive — 作業用メモの保管

このディレクトリには、開発の途中で使った**作業用の一時メモ**を保管しています。役目を終えた
（が、履歴として残す価値のある）ドキュメント群です。設計の「正」ではありません。

正となる設計ドキュメントは [`docs/`](../) 直下を参照してください
（要件定義書 / DB設計書 / ER図 / アーキテクチャ設計書 / 実装ガイドライン / スコアリング設計 / DESIGN）。

## 保管物

- **デザイン現状メモ.md** — デザイン刷新に着手する前の、現状デザインシステムの棚卸しメモ（Claude Design 壁打ち用）。刷新完了により役目終了。
- **本戦フェーズ実機確認メモ.md** — 本戦フェーズ（予選ブロック→総当たり→順位→決勝T）実装中の実機確認チェックリスト。実装完了により役目終了。
- **デザイン刷新-引き継ぎメモ.md** — デザイン刷新をセッションをまたいで継続するための引き継ぎメモ。全画面の刷新完了により役目終了。
