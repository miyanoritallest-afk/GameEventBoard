# デザイン現状メモ（Claude Design 壁打ち用）

最終更新: 2026-07-07
目的: Claude Design で「AI 作成っぽさ」を脱却するための壁打ちを始めるにあたり、**現状のデザインシステムを正確に棚卸し**して渡す。Claude Design にリポジトリを読ませる際、この 1 枚で「今どうなっていて・何が意図で・どこがギャップか」を掴めるようにする。

---

## 0. アプリの性格（誰の何か）

- **プロダクト**: Matchpoint — ゲーム大会運営ツール（イベント募集・チーム編成・対戦表・順位・通知）。
- **主ユーザー**: Overwatch 2 コミュニティの主催者・参加者。日本語 UI。
- **目指す雰囲気（方針・未実装）**: ダーク基調・クール・e スポーツ調。FPS コミュニティに刺さる「本気の大会運営」感。
- **今の見た目の問題（本人の言葉）**: 「AI 作成っぽい」。没個性で、上記の方針が見た目に出ていない。

---

## 1. 技術スタック（実装は必ずこの作法で）

- Next.js 16（App Router）+ TypeScript
- Tailwind v4（`@theme inline` / oklch 変数ベース）
- shadcn/ui（ただし導入済みは 4 コンポーネントのみ・下記）
- フォント: **Geist**（本文）/ **Geist Mono**（等幅）— `next/font/google`
- ダーク切替の仕組み: `.dark` クラス変数方式（`@custom-variant dark`）

---

## 2. 現状のデザイントークン（`src/app/globals.css`）

### 色 — ⚠️ ここが「AI っぽさ」の主因
- **全色が無彩色**: light も dark も `oklch(L 0 0)`（彩度 0 = グレースケール）。**shadcn デフォルトテンプレのまま**で、ブランドカラー・アクセントカラーが一切ない。
- OW2 らしさ（例: オレンジ #F99E1A 系）や、大会運営の「勝敗・進行」を色で伝える設計がゼロ。
- `--chart-1..5` も無彩色。順位表・対戦表を色で識別できない。

### ダークモード — ⚠️ 中途半端
- `.dark` の色定義は存在するが、**`<html>` に `.dark` が付いていない**（`layout.tsx`）。→ **サイト全体は実質ライトモード**。
- 例外: 共通ヘッダー（`site-header.tsx`）だけ `className="dark"` を直書きしてヘッダーのみダーク。
- つまり「ダーク基調」という方針が実装されていない（意図と実装のギャップ）。

### タイポ
- 見出し専用フォントなし（`--font-heading` は `--font-sans`＝Geist と同一）。
- 見出しは各画面で `text-lg font-bold` 等を手書き。タイポスケールの体系なし。

### 角丸・余白
- `--radius: 0.625rem` を基準に `--radius-sm..4xl` を派生（この体系は良い）。
- 余白・間隔のトークンは無し（各画面で `gap-4` 等を都度指定）。

---

## 3. コンポーネントの現状

- **shadcn 導入済み**: `button` / `calendar` / `popover` / `alert-dialog`（`src/components/ui/`）。
- **共通**: `site-header`（全ページ共通ヘッダー）/ `datetime-picker`（自作・JST 入力）/ `notifications-realtime`。
- **それ以外は生 Tailwind 手書き**: カード・リスト・バッジ・フォーム・タブ・テーブル等は各ページで直接クラス指定。→ 画面ごとに微妙に不揃い＝「バラバラな AI 生成感」の一因。

---

## 4. 代表的な UI 要素（すでにあるパターン）

- **バッジ**: 「公開中」「参加確定」「承認済み」等の状態ラベル（生 span + Tailwind）。
- **カード**: イベント一覧・日程カード（🔴公式戦 / 🔵スクリム / 🟢練習 の絵文字で種別表現）。
- **通知バッジ**: 🔔＋未読数の赤丸（`bg-primary`＝今は無彩色なので目立たない）。
- **フォーム**: イベント作成（日時ピッカー・スコアリング設定・本戦設定など密度が高い）。
- **チーム編成**: D&D でメンバーをレギュラー/リザーブに配置（情報密度が最も高い画面）。

---

## 5. Claude Design に壁打ちしてほしいこと（今回のスコープ）

1. **デザイン言語の確立**: 色（ブランド/アクセント/状態色）・タイポスケール・余白リズム・角丸・エレベーションの体系を決める。まず **1 代表画面**で確立し、他画面へ展開する方針。
2. **ダーク基調の実装方針**: サイト全体をダークにするのか、ライト/ダーク両対応にするのか。今の「ヘッダーだけダーク」の不整合を解消する。
3. **e スポーツ調の落とし込み**: OW2 コミュニティに刺さる方向性を、けばけばしくならない範囲で（大会運営ツールとしての可読性・情報密度を損なわない）。
4. **状態と進行の色設計**: 勝敗・順位・参加状態・通知など「運営で意味を持つ状態」を色で伝える設計。

### 最初の代表画面（デザイン言語を確立する対象）
→ **イベント詳細ページ**（`src/app/events/[id]/page.tsx` 系。公開状態の表示・状態バッジ・日時メタ・応募/フォローボタン・本戦導線などが一通り揃う「アプリの顔」）。ここで色/タイポ/余白/状態色/カード/ボタン/バッジの体系を確立し、一覧・チーム編成・対戦表へ展開する。

---

## 6. 実装時の制約（Claude Code が守る前提。Design 側も念頭に）

- 情報密度が高い画面（チーム編成・対戦表）が多い。装飾より**可読性・一覧性**が優先。
- 日本語主体（フォントの日本語グリフ・行間に注意）。
- アクセシビリティ: 状態を色だけに依存させない（絵文字/ラベル併用は既存方針）。
- 実装は必ず本プロジェクトの Tailwind v4 + shadcn の作法で行う（Design の生成物はプロトタイプ＝そのままコピペしない）。
